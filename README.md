# SAP Inside Track Kolkata 2026

This is a JavaScript React + Vite project. It preserves the supplied component structure, Tailwind styling, reveal effects, floating images, marquee, hover states, and responsive layouts.

## Run locally

1. Install [Node.js 18+](https://nodejs.org/).
2. In this folder, run:

   ```bash
   npm install
   npm run dev
   ```

3. Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The generated `dist/` folder is a portable static production build. The supplied images use their original Unsplash URLs, so an internet connection is required for the photography to load.
